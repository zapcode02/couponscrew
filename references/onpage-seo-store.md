# On-Page SEO Rules — Store Pages

> This file is self-contained. Read it fully before editing any store page.
> When keywords + a target page are provided, apply these rules to that page's title, meta description, slug, body copy, headings, FAQ, images, and internal links — without rewriting or restructuring existing sentences. Insert keywords into natural gaps in the existing language. If no natural gap exists in a section, rephrase that one sentence minimally — never rewrite whole paragraphs to force a fit.

---

## How This File Is Used

You will be given two things:
1. A keyword set — one Primary keyword + three Secondary keywords
2. A target page (existing store page, or a new one to build)

Apply the rules below to that page only. Do not touch other pages. Do not change tone, voice, or existing sentence structure beyond what's needed to fit a keyword naturally.

**Keyword set format:**
```
Primary:    [store name] coupon code
Secondary 1: [store name] discount code
Secondary 2: [store name] promo code
Secondary 3: [store name] sales today   (or "offers today" — confirm exact phrase before starting)
```

---

## Final Keyword Density Targets

| Keyword | Total count (full page) |
|---|---|
| Primary | **5** |
| Secondary 1 | **3** |
| Secondary 2 | **3** |
| Secondary 3 | **2** |

**Total keyword instances across the page: 13.**
At a ~1,200-word body this is roughly 1.1% density — well inside safe range (spam risk generally starts above ~2-3%). Do not exceed these counts. One under is acceptable; one over is not.

"Full page" = title + meta description + slug + body copy + FAQ questions/answers, combined.

## Designated Placement Map

Every keyword mention has an assigned home. Do not place a keyword "wherever it fits" — each instance below belongs to a specific slot. This is what keeps mentions reading natural instead of stuffed.

### Primary Keyword — 5 total
| # | Slot |
|---|---|
| 1 | Title tag / H1 (same instance — do not count separately) — first 3 words |
| 2 | Meta description — first clause |
| 3 | URL slug |
| 4 | First 100 words of body copy — opening sentence of the main SEO section |
| 5 | One H2 or H3 heading, phrased naturally |
| — | Optional 6th natural mention in closing paragraph is NOT allowed — stop at 5 |

Note: title tag and H1 are treated as **one** placement, not two, since they're usually the same text.

### Secondary 1 — 3 total
| # | Slot |
|---|---|
| 1 | Meta description |
| 2 | "Types of Offers" section (or equivalent) — body |
| 3 | One FAQ answer, OR "Why CouponsCrew" section — pick whichever has a natural gap |

### Secondary 2 — 3 total
| # | Slot |
|---|---|
| 1 | Meta description |
| 2 | "How to Use" / redemption steps section — body |
| 3 | One more natural mention in the intro or closing paragraph |

### Secondary 3 — 2 total
| # | Slot |
|---|---|
| 1 | Meta description |
| 2 | "Seasonal Sales" section, OR closing CTA paragraph |

**Rule: minimum one full sentence gap between any two keyword mentions.** Never stack keywords in adjacent sentences, regardless of which keyword.

## Meta Title Formula

```
[Primary Keyword] — [Max Offer] + [Second Benefit] | CouponsCrew
```

- Primary keyword = first words of the title, no exceptions
- Max % offer must be visible — this is the click driver
- Under 60 characters total
- Don't add month/date unless the page is explicitly date-stamped evergreen content
- `| CouponsCrew` always at the end

**Example:**
`Pepperfry Coupon Code — 75% OFF + 20% Cashback | CouponsCrew`

---

## Meta Description Formula

```
Verified [Primary] & [Secondary 2] – get up to [max offer]. Best [Secondary 1] & [Secondary 3]. Updated daily on CouponsCrew.
```

- 148–162 characters total
- Primary keyword in the first clause
- All 3 secondary keywords appear once each, naturally
- Max offer + second benefit both visible — CTR signals
- Always ends with "Updated daily on CouponsCrew" — freshness + trust + brand
- Must stand alone — don't write it as a continuation of the title sentence

**Example:**
`Verified Pepperfry coupon code & Pepperfry promo codes – get up to 75% OFF furniture + 20% cashback. Best Pepperfry discount code & sales today. Updated daily on CouponsCrew.`

## The 6 Mandatory Slots — Every Store Page

### 1. Title Tag
Primary keyword at the start. 50–60 characters. Max offer visible.

### 2. First 100 Words of Body Copy
Primary keyword present. Direct answer up front — what offers are live, max saving, right away.

### 3. At Least One H2 Heading
Carries a secondary keyword or a question-form query.
Example: `How to Use a [Store] Coupon Code` / `[Store] Discount Code — Types of Offers`

### 4. Image Alt Text
Describes the image naturally; keyword only if the image actually depicts the subject. Decorative images get `alt=""`. Does **not** count toward the 13-instance keyword total — it's a separate signal.

### 5. Meta Description
148–162 characters, all 4 keywords present, max offer visible.

### 6. URL Slug
Primary keyword, lowercase, hyphens only, under 60 characters, no stop words.
Correct: `/stores/pepperfry-coupon-code`
Wrong: `/how-to-find-the-best-pepperfry-coupon-code-today`

## FAQ Section Rules

- 4–8 questions per page, each phrased as a real search query
- At least one question contains the primary keyword naturally
- One question/answer can carry a secondary keyword — but only if that secondary hasn't already hit its target count elsewhere; use a synonym here instead if it has
- Answers: 2–4 sentences, one keyword maximum per answer — never stuff primary and secondary into the same answer

---

## Internal Links

- 3–5 internal links per page
- Descriptive, keyword-forward anchor text only — never "click here" / "read more" / "this article"
- Correct: `Pepperfry sofa offers`, `Pepperfry discount code for furniture`
- Anchor text does not count toward the 13-instance keyword total

---

## External Links

- 2–3 links to authoritative sources relevant to the page (the store's own official site, a relevant industry/news source)
- Open in new tab, `rel="noopener"`
- Sponsored/affiliate outbound links get `rel="nofollow"` or `rel="sponsored"` as appropriate

---

## Images

- Alt text on every image; keyword only where the image depicts the subject; `alt=""` for decorative images
- Descriptive filenames, hyphenated (e.g. `pepperfry-coupon-code-banner.webp`)
- WebP format, compressed under 200KB
- Width/height attributes specified to prevent layout shift
- Lazy loading for below-fold images

---

## Freshness Signal

- If the page claims "updated daily" or similar, display a visible "Last updated: [date]" element on the page itself, not just in the meta description
- Update this date whenever coupon/offer content on the page is actually refreshed

---

## Copy Quality Rules

- Readability: 8th–10th grade level
- Active voice preferred
- Short paragraphs: 1–4 sentences
- Bullets/numbered lists where they aid scanning (e.g. steps to redeem a code)
- Length should roughly match top-3 competitor pages for the same keyword, within ~20%
- Bold key phrases sparingly — not every keyword instance

---

## Headings Hierarchy

- Exactly one H1 per page, contains the primary keyword
- H2 → major sections, use secondary keywords or question-form phrasing
- H3 → subsections, more specific/long-tail phrasing
- Never skip a level (H1 straight to H3 is wrong)
- Not every heading needs a keyword — some should simply describe the section plainly

---

## Schema Markup (Correct Types for This Site)

CouponsCrew is an affiliate aggregator, not a local service business. Do **not** use `LocalBusiness` schema on store or any other page. Use instead:

- `Organization` — site-wide
- `WebSite` — site-wide, with `SearchAction` once `/search?q=` is live
- `CollectionPage` / `ItemList` — store, category, and deals listing pages
- `FAQPage` — wherever an FAQ section exists
- `BreadcrumbList` — every page

---

## What NOT to Do

- Do not exceed the count for any keyword (Primary 5 / Sec1 3 / Sec2 3 / Sec3 2). One under is fine, one over is not.
- Do not place two keyword mentions in adjacent sentences — always leave at least one sentence of gap.
- Do not repeat the exact same secondary keyword phrase in two adjacent paragraphs — use a synonym instead once a slot is filled elsewhere nearby.
- Do not keyword-stuff the FAQ — one keyword per question, one per answer, never both primary and secondary in the same answer.
- Do not rewrite existing sentences wholesale to fit a keyword — find the natural gap and insert cleanly; only rephrase the single sentence if no gap exists.
- Do not use stop-word-heavy slugs.
- Do not put keyword alt text on purely decorative images — use `alt=""`.
- Do not use `LocalBusiness` schema anywhere on this site.
